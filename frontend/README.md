# Frontend Kdosh IA Lab

Interfaz React para probar modelos de OpenRouter y consultar PDFs procesados temporalmente por el backend.

## Inicio

1. Inicia el backend en `../backend` con `pnpm dev` y una `OPENROUTER_API_KEY` configurada.
2. Ejecuta `pnpm dev` en este directorio.
3. Abre `http://localhost:5173`.

Vite redirige `/api` y `/health` al backend en `http://localhost:3001` durante el desarrollo.
